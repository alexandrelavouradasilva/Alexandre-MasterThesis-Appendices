# Python Automation & Processing Scripts

This folder contains all the Python scripts developed for the thesis. Detailed explanations of the methodology and data flow are included as docstrings inside each individual script.

* **`cruciform_automation.py`**: Automates Abaqus simulations for the cruciform test (CPB'06 and Swift law).
* **`data_extraction_odb.py`**: Parses `.odb` files to extract reaction forces and logarithmic strains.
* **`optuna_optimization.py`**: Neural network architecture optimization using Optuna.
